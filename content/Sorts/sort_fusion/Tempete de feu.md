### Chaleur douloureuse
Vous avez de nouveaux effets passifs dans la tempête.

|                        | Niveau 1    | Niveau 2    | Niveau 3    | Niveau 4    |
| ---------------------- | ----------- | ----------- | ----------- | ----------- |
| Chaleur<br>douloureuse | Dégâts +1d6 | Dégâts +2d6 | Dégâts +3d6 | Dégâts +4d6 |

### Écho de feu

Le prix à payer pour lancer les sorts de feu est réduit de moitié si le tempête est au niveau adéquat, et vous pouvez le lancer depuis n'importe où dans la tempête. 


| Niveau tempête                                                                    | Niveau 1 | Niveau 2 | Niveau 3 | Niveau 4 |
| --------------------------------------------------------------------------------- | -------- | -------- | -------- | -------- |
| Réduction par 2 des <br>sorts de [[Manipulation du feu (pyromancie)]] (minimum 1) | 1-8      | 1-16     | 1-32     | 1-64     |
|                                                                                   |          |          |          |          |

Par exemple, dans une tempête de niveau 2, les sorts de pyromancie de 1 à 16 points de malfaisance ne coûtent que la moitié à être lancés (et l'action est également réduite si applicable), et peuvent être lancés de n'importe où dans la tempête. 
Note: cela ne s'applique qu'à vous.
